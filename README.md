# Web Scraping and Data Preparation Project

## Overview

This project collects book information using Python web scraping
and prepares the data for analysis.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- Streamlit

## Data Collected

- Book Title
- Price
- Availability
- Rating

## Data Preparation

- Price cleaning
- Rating conversion
- Missing value checking
- Duplicate checking

## Analysis

- Total number of books
- Average price
- Minimum price
- Maximum price
- Average rating
- Rating distribution
